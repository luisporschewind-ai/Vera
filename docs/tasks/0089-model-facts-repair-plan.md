## 约束与审查重点

- 同一隔离工作树继续修改，保留既有工作；不提交、合并、安装或改宿主配置。
- 审批决定只来自 Core ApprovalRequest/ResolveApproval；工具正文中的同名字段不能覆盖结果外层。
- 历史摘要只证明过去事件，不证明当前 Grant 有效，不能恢复权限或变成系统指令。
- 不保存新的一份文件全文、diff、命令输出到历史事实；只投影固定字段、限制条数/字段长度并脱敏。
- 旧会话无这些事实时明确证据可能缺失，不编造补全；保持旧记录可读。
- UTF-8 文本、字面反斜杠、换行、截断分别验证。byte_count/hash 仅描述实际展示内容，不宣称原文件完整字节证据。
