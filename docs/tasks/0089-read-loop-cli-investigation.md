1. Core：普通工具轮次不因固定 8 条阈值丢弃；按真实请求预算裁剪。保留有界的执行事实摘要（名称、目标、状态、截断/省略标记、引用），正文允许裁剪；摘要不构成当前权限或模型指令，不含未脱敏正文。保持 assistant/tool 配对与预算上限。

3. 模型事实：明确“正文已省略”与“未执行”的区别；依据 Core 执行事实报告操作史，未知仍报告未知。不能保证自由文本永不出错，不靠隐藏事件修饰事实。
