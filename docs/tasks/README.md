# Tasks

Task records translate an accepted specification or repository goal into one reviewable unit of work.

## Convention

- Name files `NNNN-<topic>.md` using the next sequential number.
- Declare one status: `Planned`, `In progress`, `Blocked`, or `Done`.
- Link the governing specification and decisions when they exist.
- State the goal, scope, acceptance checks, and verification evidence.
- Assign one primary implementation Agent. Other Agents or tools remain read-only reviewers or researchers unless ownership is explicitly transferred.
- Close a task only after its checks run and its documentation matches the delivered behavior.

The active task is linked from `docs/STATUS.md`.
