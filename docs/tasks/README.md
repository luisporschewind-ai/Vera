# 任务记录

任务记录把已接受规格拆成可执行、可验证、可独立提交的实施步骤。

## 约定

- 文件按下一个连续编号命名为 `NNNN-<topic>.md`。
- 状态只使用 `Planned`、`In progress`、`Blocked` 或 `Done`。
- 存在上游规格或架构决策时必须链接。
- 明确记录目标、范围、验收检查和验证证据。
- 每项任务只分配一个主实现 Agent；除非明确转移所有权，其他 Agent 或工具只负责只读研究与复核。
- 只有检查通过且文档与实际行为一致后才能关闭任务。
