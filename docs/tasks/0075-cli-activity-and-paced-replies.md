## 结果

实现与本地提交均保留在独立工作树中：

- 活动状态由 Event 与当前 Run 的 `assistant.delta` 投影；首段文本切到 Replying，工具及验证结束后回到 Processing，迟到帧不覆盖新 Run 或终态。
- 工作轨使用 Thinking、Replying、Working 三类固定宽度轻动效；审批为静态等待，完成、取消、失败在时间线留下结果。无动画与 ASCII 环境保留文字及静态标记。
- 助手块保留完整权威正文，只对渲染后的视觉行限流；大量行自动追赶。非流式回答同样渐进显示，`Done` 等最后一行可见后出现；审批、失败、取消立即冲刷待显示内容。完成事件原有的通用状态卡在 TUI 中由 `Done` 取代，避免提前泄露完成状态。
- 复制读取完整正文；滚离底部不强制跟随；Resize 后重新排版 Markdown、代码块与表格。

验证：

- 定向状态、动效、逐行显示及终端布局测试：`87 passed`。新增用例覆盖流式/非流式、无回答时的 Done、Done 时序、审批、失败、取消、复制、滚动和 Resize。
- 非 live 回归：`1186 passed, 2 skipped`，耗时 223.58s。命令使用本仓库虚拟环境的 `bin` 置于 `PATH`，并以 `PYTHONPATH` 明确绑定此独立工作树的 `src`；排除了两个需要离线 wheel 安装的测试文件。
- Ruff check、Ruff format check、Mypy（六个受影响源文件）、`git diff --check` 均通过。
- 首次全量测试在未补齐虚拟环境 `PATH` 时出现 50 失败、1 错误；代表性失败补齐 `PATH` 后通过。离线 wheel 安装仍因共享 uv 缓存缺少 `openai>=2,<3` 而无法验证，属于环境阻塞。
