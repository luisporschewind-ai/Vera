# Vera CLI 视觉 Token 与标识

**状态：** Accepted  
**日期：** 2026-09-16  
**所属阶段：** 阶段 7——CLI 体验收口与个人主力化  
**来源：** 用户在对照 [阶段七视觉评审](../evals/phase-7-visual-review.md) 三套原型后明确选择  
**实施：** 任务 [0039](../tasks/0039-cli-brand-theme-and-startup-chrome.md)、[0040](../tasks/0040-timeline-composer-and-navigation-polish.md)

## 目的

冻结 Vera TUI 的语义颜色、标识三形态和窄屏降级规则，使 0039 起的实现只投影这些约定，不再现场发明视觉规范。本规格不改变 Core、审批、权限或结构化 Event。

## 已接受方向

| 项 | 选择 |
|---|---|
| 标识 | 方案 A 字标 `VERA`；进场为四行加粗点阵，任务后一行拉丁字 |
| 80×24 品牌区 | 进场四行欢迎卡；本进程第一次任务后一行 |
| 色彩 | 下方深海 / 高对比 / 无色三套 |
| 时间线主轴 | 连续对话；最近用户消息钉顶，Diff/审批是证据不是主轴 |
| 默认工具披露 | 一行摘要（动作、目标、状态、耗时）；状态组默认收起 |
| 工作轨 | 固定在 Composer 上方；当前动作与本轮步骤 |
| 60×16 状态带 | 不换另一套紧凑布局；能显示多少显示多少，模型名尽量保留 |
| 工作状态 | 固定在输入框上方；底栏不再显示正在做什么 |

| 进场标识 | 无框欢迎卡；四行点阵 Logo 在左，右侧版本/路径/模型；有卡才波动 |

## 语义 Token

TUI 只使用这些名字。实现映射到 Textual theme / CSS 变量，不得在 Widget 里写散落的装饰色。

| Token | 深海默认 | 高对比 | 无色 |
|---|---|---|---|
| `background` | `#0B1C28` | `#000000` | `#1A1A1A` |
| `surface` | `#122433` | `#000000` | `#2A2A2A` |
| `surface_elevated` | `#1A3144` | `#000000` | `#222222` |
| `text_primary` | `#D7E4EE` | `#FFFFFF` | `#E0E0E0` |
| `text_muted` | `#7E96A8` | `#FFFFFF` | `#B0B0B0` |
| `logo` | `#548EA0` | `#FFFF00` | `#B0B0B0` |
| `accent` | `#3D7A8C` | `#FFFF00` | `#B0B0B0` |
| `success` | `#4A8B6F` | `#00FF00` | `#C8C8C8` |
| `warning` | `#B08A4A` | `#FFFF00` | `#D0D0D0` |
| `danger` | `#A85A5A` | `#FF4444` | `#E0E0E0` |
| `focus` | `#5B9BB0` | `#FFFF00` | `#F0F0F0` |
| `diff_add` | `#3D6B55` | `#00FF00` | `#E0E0E0` |
| `diff_remove` | `#8B4A4A` | `#FF4444` | `#E0E0E0` |

深海 Diff 行在可用颜色时，新增行文字可用 `#7EB89A`、删除行文字可用 `#D98989`，底仍用对应 Token。无色与高对比只使用表中值。

状态不得只靠色相：批准/拒绝/取消用括号标签；工具用「完成」「失败」等文字；进度用短条与已用/上限数字。移除颜色后仍须可理解。

内置主题名保持 `default`（深海）、`high-contrast`、`no-color`。`NO_COLOR`、`TERM=dumb` 走无色。不引入可执行主题文件或第三方主题市场。

## Logo 三形态

字标内容一律是拉丁字母 `VERA`，不使用 V 星点母形，不依赖 Nerd Font 或 Emoji。

| 形态 | 何时选用 | 行内容 | 最大行数 |
|---|---|---|---|
| `full` | 本进程尚未发出任务，且 Unicode 可用 | 27 列 × 4 行盲文点阵，严格采用已接受 V4 字形；右侧三行：`Vera` 与包版本、工作区全路径、模型与推理 | 4 |
| `compact` | 本进程已发出第一次任务 | 单行拉丁 `VERA` 与全路径，中间两个空格，不拉到两端 | 1 |
| `ascii` | Unicode 不可用 | 与 `full`/`compact` 同行数；点阵用 `.`，缩行仍为 `VERA` | 与上相同 |

进场（含 `vera -c` / `-r`）先出欢迎卡。本进程第一次非斜杠任务发出后收成一行，`/new`、`/clear` 也不再展开；退出后再进 `vera` 才再次出卡。窄屏不换另一套布局，同一结构裁切。无框，只留外围 margin。波动只打在四行点阵上，且仅当欢迎卡可见；一次只走一条柔和亮带，从左下到右上，约 2.5 秒一巡，对比克制，不用 `dim`。`VERA_NO_ANIMATIONS`、无色或减少动效时为静画。

2026-09-24 用户确认「就按这一版本改，百分百实现它」。[V4 设计图](../evals/artifacts/vera-logo-v4.png)与[冻结点阵/字符模板](../evals/artifacts/vera-logo-v4.json)为本次字形权威，取代旧三行字形。每字 12×16 点，字间 1 个完整空白字符；`A` 下摆外撇、`R` 斜腿独立。加粗通过点阵自身笔画实现，不叠加终端 bold，以免字形再次粘连。静态深海色使用 `logo`；原有单条扫光仅变化颜色，覆盖全部 27 列 × 4 行，高对比/无色保持静态语义色。ASCII 以相同字符格的 `.`/空格回退（不能表达格内的 8 个盲文点）。右侧仍为三行事实，第四行留空。

字符与点位必须逐项一致；不同终端字体与行距会改变物理像素，实际显示须在用户 Terminal.app 验收，不将像素跨字体完全相同列为已验证事实。

2026-09-24 用户确认实际效果：「OK，效果可以」。V4 Logo 字形修正已通过本次人工视觉验收。

`accessible_label` 固定为 `Vera`。箭头、盒线、进度条不属于 Logo。不使用 V 星点母形。

欢迎卡不写「新会话」或时钟。工作区路径在家目录下写成 `~/…`。缩行后 `VERA` 与路径靠近，左右与其它条带同为 2 列 padding。

## 桌面延展原则

阶段十桌面若沿用本标识：窗口标题与关于页使用字标 `VERA`；不在本阶段产出应用图标、菜单栏或 `.icns`/PNG。母形方案已否决，桌面图标若将来需要，另开规格，不得把未选的 V 星点当作已冻结资产。

## 时间线、工具与状态带

- 对话主轴：用户消息与助手回复。最近用户消息在浏览其后续内容时钉在时间线顶部，右侧时间为权威 Event/Turn 的本地 12 小时制，如 `12:49 PM`、`9:21 PM`；钉顶条同一格式。下一条用户消息替换锚点。锚点不覆盖审批、未读或 Composer。
- Diff、审批、验证、失败权重大于普通工具日志，但不使用大面积警示底。
- 默认工具块一行：`动作  目标  · 状态 · 耗时`。正文按需展开。120×40 可以增加证据密度，不得改变操作语义，也不得把展开两行设为默认。
- 进场顶栏为无框欢迎卡：左四行加粗点阵 `VERA`，右为 `Vera` 与包版本、全路径、模型与推理。第一次任务后收成一行 `VERA  ~/path`。不另做图形 Logo。
- 助手 Markdown 管道表按内容宽度排成表；代码围栏同样按该宽度布局。散文、路径与 CJK 仍按词界折行，不从标识符中间切断。
- Diff 行用视觉 Token 的增减色；过长行在词界续行，不从标识符中间切断。
- 工作轨固定在 Composer **上方**：运行中显示当前动作、目标、本轮步骤（如 `读取 → 提出变更`）和取消提示；失败也留在此轨。空闲或已完成时隐藏，不占行。
- 时间线工具组与状态组默认收起；失败展开。Diff、审批、失败块仍在对话流展开。
- 底栏左侧：有 Git 分支才显示分支（脏工作区带 `*`），然后 `审批 {mode}`，然后「会话上下文」短条与已用/上限（满 1000 字节起用 `K`）。无分支则跳过，不写「非 Git」。未保存仍可挂左侧。右侧为模型名与有效推理强度。不再显示「正在读取 / 已完成」。
- 窄屏不换布局：同一左右结构，能显示多少显示多少；不要为了给上下文让路而先丢掉模型名。
- 推理强度只显示 Core/Provider 权威值；没有权威值时为「模型默认」或「不可用」，不得从模型名或回答长度推断档位。

## 非目标

- 不修改 Plain/JSON 语义，不让未来桌面端解析人类 CLI 文本。
- 不在本规格实施时引入 Electron 或桌面资源。
- 不把 Codex、Claude Code、Grok 的商标或字形写入 Vera 资产。

## 验收

- 0039 使用本表 Token 与 `full`/`compact`/`ascii` 阈值，不另造色值或母形。
- 无色、高对比、ASCII 下标识仍为可读的 `VERA`，状态仍可读。
- 60×16、80×24、120×40 进场 Logo 均为 4 行且 Composer 可见；首次任务后统一缩为 1 行。
