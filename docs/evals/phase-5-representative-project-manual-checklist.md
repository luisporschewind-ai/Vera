## 共同准备

1. 备份选定工程到独立副本目录。
2. 在副本目录执行 `vera --help`，再按需使用默认 TUI / `--plain` / `--json`。
3. 每个审批边界明确输入 `approve`、`reject` 或 `cancel`。
4. 结束后核对本副本与备份的预期差异；不要在原工程上试验。
